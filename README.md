# Bar Estimate — калькулятор франшизы пивного бара

Локальное приложение для **Windows 10/11 x64**. Русский тёмный интерфейс, прайс из предоставленной таблицы (66 позиций), редактирование сметы, сценарии Мин / База / Макс, сохранение проектов, Excel-экспорт и JSON-копии. После установки интернет не нужен.

## Установка

Запустите `Bar-Estimate-1.0.0-Setup.exe`, выберите папку и завершите установку. Приложение устанавливается для текущего пользователя, права администратора не требуются. Установщик не имеет цифровой подписи издателя; Windows может показать предупреждение SmartScreen. Устанавливайте файл из доверенного источника. Контрольная сумма SHA-256 поставляется рядом с ним.

1. Настройте площадь, места, краны, кухню, ремонт и каникулы.
2. При необходимости выберите сценарий цен, включите опции и измените количество или ставку в строках.
3. Нажмите «Сохранить проект». Снимок содержит свой прайс и не изменяется при обновлении цен.
4. «Выгрузить смету XLSX» создаёт Excel с итогами и всеми 66 строками; «Печать» печатает все включённые строки.
5. «JSON-копия» сохраняет переносимую резервную копию. Открывается в разделе «Проекты» → «Открыть JSON-копию».

## Обновление цен

«Загрузить данные» → XLSX или CSV → проверить предпросмотр → «Применить прайс». Можно загружать исходный Excel напрямую. Для CSV: UTF-8, разделитель `;`, `,` или табуляция. Кнопка «Скачать шаблон» выгружает текущий справочник с нужными колонками.

Обязательные колонки: ID, Раздел, Подраздел, Позиция, Тип, Ед, Мин, База, Макс, Статус, Применимость, База количества, Кол-во. Комментарий и Возврат необязательны. Для XLSX используется лист «Справочник затрат», иначе первый лист. Формулы замените готовыми значениями. Лимит 5 МБ / 2000 строк. ID уникальны.

При применении прайса сбрасываются ручные ставки, количества и выбор опций текущего черновика; параметры объекта и сохранённые проекты остаются. Ошибочный файл ничего не заменяет.

## Правила и ограничения

См. [PRODUCT.md](PRODUCT.md). Места и краны не вычисляются автоматически по площади. В контрольном листе исходного файла эти параметры отсутствуют. Девять сумм воспроизводятся при явно заданных 20 местах, 8/10/12 кранах для площадей 50/65/80 м², ремонте и каникулах по 2 месяца. Это тестовые конфигурации, ожидающие подтверждения владельцем прайса, а не правило проектирования. Начальная конфигурация: 65 м², 20 мест, 10 кранов, без кухни.

Страховые взносы указаны в исходнике готовой суммой. При изменении ФОТ скорректируйте взносы вручную. Возвратные суммы входят в бюджет; кеги не считаются возвратными автоматически без отметки в колонке «Возврат». Расчёт предварительный.

Данные сохраняются в профиле приложения текущего пользователя Windows (обычно `%APPDATA%/bar-estimate`, хранилище Chromium). Нет облачного хранения или синхронизации. Удаление профиля уничтожает локальные проекты: регулярно выгружайте JSON-копии. Удаление приложения не удаляет профиль автоматически. Используйте условные названия объектов без персональных данных клиентов.

## Разработка

Требуется Node.js 24 и npm. Используйте существующий checkout `/workspace/123`: облачная задача уже изолирована, отдельный worktree не нужен.

```sh
npm ci
npm run dev
npm test
npm run build
npm run desktop
```

`npm run dev` — браузерная разработка на 127.0.0.1:5173; `npm run desktop` — то же приложение в Electron с локальным файлом. Для среды, где нужен только браузер и сборка Windows, установка допустима с `ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci`. Electron для целевой платформы загружает electron-builder с проверкой TLS/checksum.

```sh
npm run package:win
```

Установщик создаётся в `release/`. Windows-установщик собирается штатным NSIS с собственным сценарием установки, без Wine. Манифест удаления генерируется из фактически упакованных файлов: чужие файлы в папке не удаляются рекурсивно. Для проверки UI в этой облачной среде запустите dev-сервер, затем `npm run test:e2e` и `npm run test:a11y` (используется `/usr/bin/chromium`). Windows-установку нужно дополнительно проверить на реальной Windows: облачная машина работает на Linux.

Дизайн: [DESIGN.md](DESIGN.md), поведение: [UX-CONTRACT.md](UX-CONTRACT.md). Токены генерируются командой `node scripts/tokens.mjs`; `node scripts/tokens.mjs --check` проверяет отсутствие расхождений. Сборка включает все шрифты через системные локальные стеки; обращений к внешним API и шрифтам нет.
