# Проверка версии 1.0.0

Проверено 28.10.2026 в облачной Linux-среде.

- TypeScript и production-сборка Vite: успешно.
- `npm test`: 26 тестов, все прошли. Девять контрольных сумм исходного Excel воспроизводятся с явно заданными 20 местами и 8 / 10 / 12 кранами для 50 / 65 / 80 м². Количество мест и кранов не указано в контрольном листе, поэтому эти тестовые конфигурации не считаются подтверждённой бизнес-формулой.
- `npm run test:e2e`: 16 проверок Chromium, все прошли. Параметры и кухня, ошибка ввода, сохранение/перезагрузка, ошибочный CSV, исходный XLSX, предпросмотр и применение, Escape и возврат фокуса, поиск, Excel с 66 строками и точным итогом, JSON-восстановление, офлайн-расчёт, узкий экран, уменьшенная анимация, подтверждение удаления, отсутствие ошибок JavaScript.
- `npm run test:a11y`: axe WCAG A/AA на расчёте, импорте, прайсе и проектах — 0 автоматически обнаруженных нарушений. Автоматическая проверка не заменяет полный аудит со скринридером.
- `node tests/production.mjs`: готовая сборка запущена через статический сервер, исходный XLSX импортирован, экспорт XLSX выполнен после отключения сети. Прямой запуск file:// в системном Chromium заблокирован административной политикой облачной среды; политика не изменялась.
- `node scripts/tokens.mjs --check`: успешно. DESIGN.md проверен официальным линтером: 0 ошибок; предупреждения о неиспользуемых в описаниях компонентов токенах не означают отсутствия токенов в runtime CSS.
- Статический аудит навыка дизайна: 0 нарушений. Форматирование Prettier проверено.
- Windows x64 Electron упакован, NSIS завершил компиляцию установщика и встроенного деинсталлятора с кодом 0. Упакованный HTML и JS совпадают с финальной production-сборкой. Установщик распознаётся как PE / Nullsoft Installer; SHA-256 поставляется отдельно.
